# Design Tokens — example

> **これは同梱の example**。このプロジェクトのデザイントークン定義（Tailwind config・CSS カスタムプロパティ・テーマファイル等）に合わせて**再生成すること**。
> トークン定義を持たないプロジェクトではこのファイルを削除してよい — `review-ui` は縮退動作（一般的一貫性のみの確認）に切り替わる。

## このファイルの役割

`review-ui` の Axis 2（デザイン整合）が「ハードコードされた値に対応するトークンが既にあるか」を照合するための参照。プロジェクトの実際の定義箇所（設定ファイルのパス）と、レビューで照合すべき値の一覧を書く。

## 記載テンプレート

### トークン定義の場所

- 例: `tailwind.config.ts` の `theme.extend` / `src/styles/tokens.css` のカスタムプロパティ

### 色

| トークン | 値 | 用途 |
|---|---|---|
| `primary` | `#3b82f6` | 主要アクション |
| `danger` | `#ef4444` | 破壊的アクション・エラー |

### Spacing スケール

- 例: 4px 基準（`p-1` = 4px, `p-2` = 8px, ...）。スケール外の生値（13px 等）は指摘対象

### タイポグラフィ

| トークン | サイズ / 行高 | 用途 |
|---|---|---|
| `text-sm` | 14px / 20px | 補助テキスト |
| `text-base` | 16px / 24px | 本文 |

### ブレークポイント

| 名前 | 幅 | 備考 |
|---|---|---|
| `sm` | 640px | |
| `md` | 768px | |

### テーマ

- 例: ダークモード対応あり（`dark:` バリアント必須）/ なし
