## 20260807 — design-premortem 反映（設計者反映・未承認）

**決定**: deny は最大 1 JSON（ヒットで即終了）
**理由**: 複数行ヒット時の連結 JSON が M3 の厳密 parse と衝突する
**影響**: 完了条件に「2 行とも対象」ケースと単一 JSON を追加

**決定**: M2 AFTER 追加文字は `*?[{` のみ（`.` 禁止）
**理由**: B20 `CLAUDE.md.bak` を誤 deny しないため
**影響**: 制約・完了条件に固定

**決定**: 行継続は単純 `\\\n` + CRLF 正規化。bash 完全忠実は対象外
**理由**: 善意エージェント脅威モデル。完全パーサは YAGNI
**影響**: 引用符内等の過検知/すり抜けは受容として対象外に明記

**決定**: M4 抽出法を `contract_([a-z])` / 箇条内 `(a)` / scripts↔バッククォート に固定。員数数字は本文から消す
**理由**: 散文パースの脆さを設計時点で固定しないと再発する
**影響**: README 訂正時にマーカーが機械可読であること

**決定**: M5 はキー共存に加え FCR 本文の出現位置比較（知見保存がデプロイより前）
**理由**: 「順」を完了条件に書いた以上、共存だけでは手段不足
**影響**: validate_skills に位置比較を足す。空文限界は既存群と同型で残る
