```markdown
# フォームのパターン

## 数値の入力欄

- `type="number"` ではなく `type="text"` に `inputMode="numeric"` を付ける。`type="number"` は、ブラウザによって「10,000」のようなカンマ入りの入力を空にする
- 数値にするときは、カンマを除いてから `Number` に渡す。`Number("10,000")` は NaN になり、`x <= NaN` はすべて false になって全件が消える。NaN なら絞り込まない
- 空欄と 0 は区別する（0 は「0 以下」として扱う）
- 入力欄には必ずラベルを付ける（テストで役割とアクセシブルな名前を使って探すためにも必要）
```
