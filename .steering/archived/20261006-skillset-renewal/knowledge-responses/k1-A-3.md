```markdown
# 入力欄のパターン

## 数値の入力

- `type="number"` は使わず、`type="text"` に `inputMode="numeric"` を付ける。`type="number"` はブラウザによって「10,000」のようなカンマ入りの値を空にする
- 文字列を数値にするときは、カンマを取り除いてから `Number` に渡す。`Number("10,000")` は NaN になり、`price <= NaN` は常に false なので、絞り込むと全件が消える。NaN のときは絞り込まない
- 入力欄には必ずラベルを付ける（テストでもラベルで探せる）
```
