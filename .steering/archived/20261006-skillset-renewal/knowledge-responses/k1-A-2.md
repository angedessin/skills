### 案 2：`docs/knowledge/form-patterns.md` を新しく作る

```markdown
# フォーム入力のパターン

## 数値の入力欄

- `type="number"` ではなく `type="text"` + `inputMode="numeric"` にする。`type="number"` はブラウザによって「10,000」のようなカンマ入りの入力を空にする
- 値を数値にするときはカンマを除いてから `Number` に渡す（`replace(/,/g, "")`）。NaN なら絞り込みなどの処理をしない
  - NaN のまま比べると `price <= NaN` がすべて false になり、全件が消える
- 0 と空欄は区別する（空欄 = 指定なし、0 = 0 として扱う）

## 絞り込みのロジック

- 絞り込みは画面から切り離した純粋な関数（例: `filterByMaxPrice(products, max)`）にして、単体でテストする
```
