```markdown
# フォーム入力のパターン

## 数値の入力欄

- `type="number"` は使わず、`type="text"` に `inputMode="numeric"` を付ける。`type="number"` だと、ブラウザによっては「10,000」のようなカンマ入りの入力が空になる
- 入力文字列はカンマを除いてから `Number` にする。`Number("10,000")` は NaN になる。`price <= NaN` は常に false なので、全件が消えてしまう
- 変換結果が NaN なら絞り込まない。空欄（絞り込まない）と `0`（0 以下に絞り込む）は別の値として扱う

```typescript
// Good
const n = Number(input.replace(/,/g, ""));
if (input.trim() === "" || Number.isNaN(n)) return products;
return products.filter((p) => p.price <= n);

// Bad: カンマ入りの入力で全件が消える
return products.filter((p) => p.price <= Number(input));
```
```
