```markdown
# フォームのパターン

## 数値の入力欄

- 金額などの数値欄は `type="number"` にせず、`type="text"` に `inputMode="numeric"` を付ける。`type="number"` はブラウザによって「10,000」のようなカンマ入りの入力を空にしてしまう
- 入力値は `replace(/,/g, "")` でカンマを除いてから `Number` に渡す。カンマ付きのまま渡すと NaN になる
- NaN になったら絞り込まない（全件をそのまま返す）。`price <= NaN` はすべて false になり、全件が消える
- 空欄と 0 は区別する。空欄は「絞り込まない」、0 は「0 円以下に絞り込む」
```
---
入力元: decisions.md の type="text" と 0 の扱い、review-result の #1（High）
