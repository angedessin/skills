```markdown
# フォーム入力のパターン

## 数値の入力欄

- `type="number"` ではなく `type="text"` + `inputMode="numeric"` を使う。`type="number"` はブラウザによって「10,000」のようなカンマ入りの入力を空にする
- 入力の文字列を `Number` に渡す前にカンマを除く（`replace(/,/g, "")`）。カンマが残ったままだと NaN になる
- NaN は「未入力」と同じに扱う。`price <= NaN` はすべて false になるので、そのまま比べると全件が消える
- 空欄と 0 は区別する（0 は「0 以下」という有効な条件）
```
出どころは decisions.md（type="text"・0 の扱い）とレビューの High 指摘 #1 です。
