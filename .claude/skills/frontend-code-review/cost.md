# レビューの費用の目安

SKILL.md の Step 1 が、差分の大きさと一緒に示す目安。目安を出すときは「（2026-11 の実測）」のように、下の「測った時期」の最後の年月を添える。

| 差分の変更行 | 費用 | 時間 |
|---|---|---|
| 500 行まで | 0.7〜3 ドル | 数分 |
| 2,000 行まで | 2.5〜4 ドル | 10〜20 分 |
| それより上 | 4 ドル以上 | 数十分 |

## 測った条件

- 測った時期: 2026-10〜2026-11
- Claude Code: 2.1.312〜2.1.330
- agent のモデル: review-bug・review-verify は opus、review-rules・review-test・review-ui-a11y は sonnet（`.claude/agents/` の `model:`）
- メインのセッションのモデル: 記録に無い

## 測り直すとき

モデル・料金・agent の構成（数・モデル・effort）を変えたら測り直し、表と「測った条件」を一緒に直す。数字だけを直して時期を残すと、古さに気づけなくなる。
